# ДЗ_02.Телефонная книга (Homework_02_mvc_with_classes - рефакторинг ДЗ_01)

Простой консольный проект телефонной книги, реализованный (попытка реализовать) по паттерну MVC.

## Структура проекта

- `main.py` — точка входа
- `models` — модели (данные)
    - filereader.py
    - filewriter.py
    - phonebook.py
    - contact.py
- `view` — отображение и взаимодействие с пользователем (меню, вывод, ввод)
    - view.py
- `controller` — логика работы
    - controller.py
- `utils.py` — вспомогательные функции ввода
- `data` — файл с контактами
    - phonebook.py

## Как запустить

1. Перейди в папку проекта
2. Выполни команду:

```bash
python3 main.py
